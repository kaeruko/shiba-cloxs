# しばちゃんうんちどけい

しばちゃんの一日をぐるぐる眺める、小さなWeb時計です。

## いま入っているもの

- ごはん
- わんぷろ
- あそぶ
- ねこさんにおこられる
- おやつ
- うんち
- すっきり
- ねんね

現在は絵を仮表示にしてあります。

## ローカルで見る

静的サイトなので、リポジトリ直下で任意のHTTPサーバーを起動してください。

例:

```bash
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## 絵を追加する

`assets/README.md` の手順を参照してください。

## 構成

- `index.html` - 画面
- `styles.css` - 見た目
- `app.js` - 時計とイベント切り替え
- `assets/` - しばちゃんの絵
